# Checklist: Sample Data for OCR/Parser & Validation Tuning

Vui lòng cung cấp (đóng gói thành ZIP):
1. Báo cáo Tài chính (Excel + PDF có dấu): tối thiểu 5–10 bộ, bao gồm báo cáo bảng cân đối, báo cáo kết quả hoạt động, báo cáo quyết toán.
2. Bảng cân đối phát sinh tài khoản (trial balance) xuất từ phần mềm kế toán (MISA/Fast/Bravo): 10–20 file Excel (nhiều layout).
3. Biên bản đối chiếu tiền gửi ngân hàng/kho bạc: 5 file (PDF hoặc Excel).
4. Mẫu hóa đơn, chứng từ liên quan (scan): 10–20 file (tùy có).
5. Chart of Accounts (danh mục mã TK) hiện hành (CSV/Excel).
6. Nếu có: data năm trước (để kiểm tra TK 468 continuity).
7. Quy định nội bộ: ngưỡng phê duyệt, tolerance (VND) cho đối chiếu, thời hạn lưu trữ.
8. Mẫu form xuất báo cáo quyết toán theo Phụ lục (mẫu PDF/Excel) để dùng khi sinh export.

Ghi chú: ưu tiên cung cấp dữ liệu thật (ẩn danh hoá nếu cần) để tăng chất lượng tuning.
